## Evidence and scope

H2 asks whether silence trimming, volume normalization and noise reduction improve cat situation classification under simulated household noise. No H2 improvement has been established by this contribution. The existing team model card reports exploratory 40.0% accuracy and 0.372 macro-F1 on 120 clips from six cats. These are the team's earlier results, not new measurements. The same holdout was reused after v1 failure, so it is not an untouched confirmatory benchmark.

Inspected implementation: `work/meowmemo-local-ai/train.py`, `model.py`, `server.py`, existing smoke tests, split/evaluation artifacts, root and backend model cards, setup and package documentation. Training and HTTP inference reuse `model.read_audio`: decoding, channel averaging and polyphase resampling to 16 kHz, with empty/nonfinite rejection and duration bounds. MFCC extraction performs peak normalization and pads short input. There is no explicit silence trimming or noise reduction in the inspected pipeline. Silence/short-audio abstention is not trimming. New tests exercise the existing functions; no placeholder denoiser or duplicate pipeline is introduced. Noise-reduction output validity cannot yet be tested against an implementation. On integration, require finite 1-D output at the declared rate, documented length/latency behavior, stable silent/short inputs, and paired train/inference agreement.

The full CatMeows dataset and selected 20 ESC-50 clips are absent in this checkout. Public lab previews and extras are not the full corpus. Owner recordings remain qualitative only and must never enter formal metrics, training, hyperparameter selection or test fixtures.

## Reliability implications and recommended design

1. **Imbalance:** Report all three per-class precision/recall/F1 values, confusion matrices, accuracy and macro-F1 with a fixed label order and explicit zero-division policy. Macro-F1 prevents isolation counts from dominating the mean but does not remove uncertainty in minority classes. Compare against a development-majority baseline. Fit weighting/scaling only within each training fold.
2. **Unequal cats and missing classes:** Publish the cat-by-situation matrix and per-cat counts. Clip-weighted metrics give prolific cats more influence. Also report cat-level summaries. Missing contexts can confound identity and situation; a fold lacking a class must be visible rather than dropped. Do not infer context-independent breed or sex effects from this small dataset.
3. **Generalization:** Preserve cat separation for all clean/noisy variants, preprocessing tuning and model selection. Leave-one-cat-out evaluation gives 21 interpretable held-out-cat folds if the full dataset is present. Use development-only nested/grouped selection; report folds with missing classes and avoid choosing methods on final test cats. LOCO is a proposed extension, not a result produced here.
4. **Uncertainty:** Bootstrap entire held-out cats, not clips or noise variants, with fixed seeds and a declared repetition count. Resample cats with replacement, retain every recording/condition for each draw and compute the paired macro-F1 difference between preprocessing arms. Use the same cat draws for both arms. Declare whether the target is clip-weighted or equal-cat performance; report percentile intervals and their instability with only six test cats. Existing reused test results remain exploratory regardless of interval width.
5. **Noise:** Predeclare the 20 selected ESC-50 clips and retain original source IDs/folds. Split original noise sources before cropping/repetition or mixing; multiple files can derive from one Freesound source. Keep all derivatives within the same partition. Evaluate clean plus 20/10/5 dB using paired cat clips and deterministic crops/seeds. Set gain from measured signal/noise power at a common sample rate; define silence handling, verify achieved SNR, avoid clipping, and log gains/crops/source IDs. Common post-mix scaling preserves SNR; independently normalizing components afterward does not. Fit denoising parameters on development data only. Simulated mixing does not reproduce all real rooms, microphones or reverberation.
6. **Processing parity:** CatMeows originals are described as 8 kHz mono; the prototype emits 16 kHz mono for YAMNet/MFCC. Upsampling does not restore frequencies above the original Nyquist limit (4 kHz). Keep original format checks distinct from inference format checks. Apply the same documented operation order and parameters to training and inference, preserve original media, and invalidate cached embeddings if processing changes. Test silence, near-silence, very short and nonfinite inputs before model calls. Retain appropriate duration guards after trimming/resampling.
