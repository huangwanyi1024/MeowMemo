# MeowMemo Peach Milk Accessories (Demo)

- `bow.png` — blue bow
- `bandana.png` — sage-green checkered bandana
- `collar.png` — brown bell collar
- `reference_sheet.png` — original design reference (not a transparent sprite)

The three accessories are individually cropped transparent PNGs extracted from the supplied concept sheet. Their alpha masks are approximate and should be visually checked in the app at actual size.

Usage: overlay one accessory on top of an existing cat sprite. Position and scale separately for sitting, sleeping, and playing poses; if an overlay cannot be aligned cleanly in a pose, hide it for that pose rather than floating it. `None` means no overlay. Keep existing cat data and appearance settings. No extra combinations or sprite generation are required for the demo.
