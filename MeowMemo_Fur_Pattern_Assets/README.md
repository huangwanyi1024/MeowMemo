# MeowMemo Fur & Pattern Assets

18 seated cat sprite variants: 3 colors (orange, gray, cream) × 3 patterns (stripes, patches, solid) × 2 fur lengths (short, long).

All sprite PNGs are independently cropped with a computer-vision estimated alpha mask from the illustration sheet. **Review edges and inspect every sprite in the browser before shipping**: automatic segmentation may leave halos or remove small tail/ear details.

These are **sitting poses only**. Do not claim sleeping/playing variants exist. For Home V3, keep existing sleeping/playing sprites or hide fur/pattern variants for unsupported poses; report that limitation.

Accessory sizing is a CSS/placement issue; reuse the separate accessory asset pack and calibrate against actual rendered cat dimensions. Do not bake accessories into the sprite variants.

For dark coat, use existing fallback or request a dedicated sprite.
