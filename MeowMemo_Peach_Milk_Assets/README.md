# MeowMemo — Peach Milk Asset Pack

Extracted from the AI-generated concept sheet. Includes 50+ cropped PNG assets grouped by category.

## Important limitations
- Individual assets are **automatically cropped**, not separately redrawn. Some have cream halos, remnants of neighboring art, or incomplete edges.
- Transparency is **approximate**, using connected-background removal. Check assets visually before production use.
- The living-room scene is a **flattened background**, not separate room layers.
- Typography and buttons should preferably be recreated as HTML/CSS, not embedded images.
- Source image resolution is 1536×1024, so individual crops are relatively low resolution.

## Folders
- `backgrounds`: room scene
- `cats`: cat characters and poses
- `furniture`: objects for composing scenes
- `decorations`: stickers and accents
- `ui`: cards and reference controls
- `branding`: logo and display title art

## Codex usage
Place this directory in `public/assets/meowmemo/`, use the PNG files as illustration layers, and implement all buttons, forms, and text with actual interactive components.
